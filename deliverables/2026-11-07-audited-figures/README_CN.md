## 在PyCharm中运行

1. 解压整个文件夹，用PyCharm打开 `URP_Audited_Figures`，选择64位Python 3.12。
2. 在终端执行 `python -m pip install -r requirements.txt`。
3. 运行根目录 `run_all.py`。它会完成数据核验、12图重绘、中文解析Word、核验Excel以及英文图册PDF。

每张图也可单独运行 `figure_scripts/figure_XX_*.py`，无需修改绝对路径。首次运行会先重建必要统计表；不会运行MCMC或遗传搜索。图形均为英文，提供450 dpi PNG、PDF和SVG。字体文件随包提供。

**2022年生物量来源已补齐。** 原论文图4-8的DI橙色柱、10个日期、单位及像素定位都能对应。重读最大差0.0762 t/ha。旧校准目标未改变，图5并列显示新读数。另发现2019年6月4日和6月12日与旧读数差0.3439、0.4149 t/ha，已单列保留，不将其藏入“全部通过”的结论。

## 复现与用途

运行 `verify_package.py` 可检查原始输入、代码哈希和已生成PNG的像素哈希。相同记录环境下进行严格像素核验；跨操作系统可能有少量字体栅格化差异，数据和统计核验另行检查。不要只复制某一个py而遗漏整个data、source、assets和evidence目录。

`data/paper/`是旧归档，只读保留；`outputs/derived/`是本次修订后优先使用的表。历史bootstrap宽度未被冒称为已找回随机状态。新区间及成对差值统计有明确脚本和种子，属于新的数值复核。

图9、11建议以横向整页或矢量格式使用，五期标签已做碰撞避让。解析Word保留了原图号，便于替换原稿；图册PDF提供较大的矢量视图。
