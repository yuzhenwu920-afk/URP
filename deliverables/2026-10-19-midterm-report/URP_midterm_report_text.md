# 创新训练项目中期报告书（研究内容已填写稿）

项目名称：基于马尔科夫链的不同灌溉方式灌溉制度优化
编号：X2026100190937；执行期：2026年；负责人：吴雨臻；成员：李承昊、段璞；导师：廖人宽教授。

项目简介（89字，含标点）：面向玉米节水灌溉，融合田间与遥感资料，利用AquaCrop模型和MCMC开展参数校准及不确定性分析，结合敏感性与多情景模拟优化灌溉制度，为提高农业用水效率、保障作物产量提供依据。

## 一、项目研究进展情况

1. 研究内容与立项任务衔接 本项目依托“吐哈盆地农业水资源节水潜力分析”，围绕不同灌溉方式下的玉米灌溉制度优化展开。目前以2019—2022年滴灌（DI）资料为基础，形成“资料整理—分阶段MCMC校准复核—生长与水量评价—Sobol分析—保产节水优化”路线，为后续不同方式情景比较建立可信基准。

2. 四年资料整理与质量核查 已整理四年气象、田间叶面积指数换算的冠层覆盖度（CC）、地上干生物量、年产量、初始土壤水及灌溉资料，统一日期、单位与产量含水率口径。逐点核对CC及生物量配对值与对应日期的逐日模拟输出；2022年补充资料已齐全，18项原模型与支持资料文件哈希均匹配。

3. 既有MCMC成果复核 复核既有两阶段校准：阶段一为CCx、CGC_CD、CDC_CD、SenescenceCD、Kcb，阶段二为WP_early、WP_late、HI0。四年共16组阶段一、4组阶段二记录，32个年度中心值可追溯。实际为每组32个walker、2000步的ensemble采样，与申请书初拟“三链1000步”有所调整，后续按实际方法报告。本轮未重跑MCMC；两阶段样本不能视作八维联合后验。

4. 模型复现与下游计算准备 已接入2022原模型，完成资料预审及冻结均值点回放；2019—2021采用已核验原输出进行四年比较。已明确Sobol八参数独立物理范围、确定性双目标优化及候选条件扰动方案，准备设计矩阵与自动化接口。完整的新真实模型Sobol及NSGA-III实验尚待执行。

5. 当前进度与立项计划比较 对照立项书2—4月资料、5—7月模型、8—10月参数优化、11—12月总结的安排，现阶段已形成四年校准成果及复核材料；遥感动态同化、滴灌与喷灌对照和正式优化结果仍需补充。本阶段训练集中于数据溯源、统计诊断、模型复现和科研表达，后续工作按原定年末成果整理节点推进。

## 二、项目研究已取得阶段性成果和收获

1. 形成可追溯的四年资料与校准证据 建立四年逐日输出、校准配对表、参数中心与采样来源记录。四年CC共48对、生物量共37对，均可回到对应日期的模型输出复算；遥感CC仅作辅助参照，未将其作为DI处理的独立验证。

2. 获得四年生长过程拟合评价 CC的R²为0.9306—0.9932，RMSE为0.0316—0.0596；地上干生物量的R²为0.9685—0.9966，RMSE为0.5562—1.2520 t/ha。四年年产量相对误差均在±5%内，最大绝对误差约4.18%。这些结果说明对现有校准资料的拟合较好，仍需独立数据评价泛化能力。

3. 完成2022模型数值复现 冻结中心点回放得到产量14.0778 t/ha、灌水量404.84 mm、季节蒸散596.7846 mm；与原汇总结果的最大差异小于1.5×10⁻¹⁴，季节水量账残差约10⁻¹² mm。这些结果支持计算复现与内部守恒，不代表田间预测误差为零。

4. 形成阶段性成果载体 形成18组四年比较图（PNG与矢量PDF）、核验工作簿、论文框架和六个同步交付包；18张PNG可由独立交付工程逐字节复现。工程验证共19项通过，其中1项调用2022真实模型检查基准、重复性与灌水量接口。现阶段成果为数据、方法及可复现工程，论文尚处于框架与结果整理阶段。

## 三、项目研究存在的主要问题及应对思路与措施

1. 跨年模型调用尚未全部贯通。 2022资料与原模型已接入，2019—2021原始模型实现仍待补充接入。下一步逐年核对源码、驱动和冻结中心点，完成基准一致性测试后再开展四年真实模型响应计算；当前不将重绘图表表述为四年模型全部重跑。

2. 采样诊断与参数补偿限制仍需保留。 现有阶段一结果尚不能按原严格诊断标准作出全面收敛认证，且两阶段样本不构成八维联合后验。将完整保留诊断与适用边界；候选方案按阶段分别扰动，并保留同阶段样本整行相关，不把相关保留行视作独立样本。

3. 敏感性与优化尚缺正式真实模型结果。 历史代理探索可用于排查流程，不能替代作物模型的敏感性排序、Pareto前沿或节水结论。后续开展重复种子、样本量稳定性和同预算算法对照；有硬约束违反或无可行解时，不输出推荐制度。

4. 与原立项范围的衔接需补充。 当前以DI为主，遥感动态同化、滴灌与喷灌对照尚无可核验的完成证据；将核查相应数据和模型适用性，与导师确认补充任务或范围调整。部分观测来自数字化，校准不等同独立验证。申请书所述效率提升30%以上仍属预期目标，不列为已实现成果。
