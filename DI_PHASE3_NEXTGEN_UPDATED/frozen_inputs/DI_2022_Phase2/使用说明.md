# 2022 第二阶段一键运行

用原来的 PyCharm Python 环境打开 DI_2022_PHASE2_ONE_CLICK.py，点击 Run 即开始：预审 → 读取第一阶段 → 固定保留样本均值 → 第二阶段 2000 步 → 输出结果。无需填终端参数。

这是依赖原项目的衔接脚本，不是包含原数据的独立安装包。默认原项目路径为 C:/Users/Lenovo/PycharmProjects/PythonProject/DI_2022_OneClick；换电脑只修改顶部 PROJECT。原项目脚本、data 文件夹和 sampling/checkpoints/canopy_transpiration 的四个 NPZ 必须完整保留，且科学设置、软件版本须匹配原链。

- 第一阶段：读取四组既有链，不重新采样；复算 ceil(5×最大tau) 预热段，使用其余样本算术均值，不使用最高采样点。
- 第二阶段：一组 ensemble，32 walkers，每个 walker 2000 步；仅采 WP_early、WP_late、HI0，保持原先验、似然和模型结构。
- 输出在本脚本旁 phase2_conditional_results；检查点只有 checkpoints/biomass_yield/ensemble_1.npz。
- 每25步保存；正常停止后再次点击 Run 会读取最后保存点并继续，不从零开始。遇到断电/强制杀进程留下 .run.lock 时，先确认无进程运行，再移除该锁文件。
- 保持脚本、数据、环境与输出位置不变才能精确续跑。需要增加总步数时，可通过 --steps 指定；修改脚本本身会触发哈希不一致，不能静默沿用旧链。
- 2步试运行保存在独立 phase2_smoke，不会作为正式结果。

结果：phase1_mean_handoff.json 保存固定点、原诊断和文件哈希；run_status.json 保存完成状态；conditional_parameter_summary.json 保存条件样本均值及分位数；conditional_mean_model.json 保存均值参数下的 DI/零灌溉模拟；conditional_phase2_diagnostics.png 保存轨迹与分布。完整样本在 NPZ 的 history/logs/accepted 中。

科学界限：第一阶段未通过原严格收敛诊断，此事实不改写。一组第二阶段 ensemble 不计算把 walkers 当独立链的 Rhat。完成2000步只标记 SAMPLING_COMPLETE_REVIEW_REQUIRED，不声称收敛或独立验证。若5tau之后没有剩余样本，不生成推断摘要并明确要求延长。现有均值及分位数仅为未认证收敛的条件样本摘要；不传播第一阶段不确定性，不是8参数联合后验，不是完整复现参考论文。零灌溉是未验证情景。此版本未包含跨第一阶段代表点的第二阶段敏感性试验，也未包含Sobol和NSGA-III。

运行时间受第二阶段单次模型耗时影响，减少到一组不等于保证10小时内完成。先观察前100步速度再估算。
